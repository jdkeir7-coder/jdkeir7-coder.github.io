About this prototype

The base map is live OpenStreetMap tile imagery — no API key needed. Routing normally runs on a real street graph fetched from OpenStreetMap's Overpass API around your start point, with lighting from OSM's lit tag and elevation from Open-Elevation. Address search (with live autocomplete) uses OSM's Nominatim geocoder.

If Overpass can't be reached — some networks block third-party API calls even when map tiles load fine — Loopline automatically falls back to a plausible, geographically-anchored street grid so route generation still works. You'll see this flagged as "approximate streets" in the status line and on the results.

These are free public services with light rate limits; for production traffic, use a paid tile provider (Mapbox/MapTiler) and self-host or cache Overpass/Nominatim.
